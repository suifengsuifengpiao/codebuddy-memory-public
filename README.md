# codebuddy-memory-public（脱敏记忆层）

用户"随风"的跨会话记忆**公开脱敏版**，供其他 AI 助手读取以了解用户背景与项目上下文。

- `助手必读.md` —— 入口：用户背景、协作偏好、项目结论速查、协作约定
- `qinqinxs_项目档案.md` —— 亲亲小说书源项目的完整技术档案（四层盾实锤、Legado 机制、版本史）

**脱敏声明**：本仓库不含对话原文、不含账号/令牌/任务 ID/运维细节。完整记忆库为私有，由用户主助手（CodeBuddy）维护，本仓库内容由其单向脱敏同步。

**维护方式**：用户主助手写档后，将脱敏文件同步推送至 GitHub 与 Gitee 两个公开远程。
